# GitHub achievement checklist

A reference for earning profile achievements through real project work. This is a planning checklist, not a claim that GitHub has awarded these badges.

| Achievement | Community-reported initial requirement |
| --- | --- |
| Pull Shark | Author two pull requests that are merged. |
| Quickdraw | Close an issue or pull request within five minutes of opening. |
| YOLO | Merge your own pull request without a review. Use normal review practices for substantive code changes. |
| Pair Extraordinaire | Co-author a commit with a real collaborator in a merged pull request. |
| Galaxy Brain | Have two repository Discussion answers accepted. |
| Starstruck | Own a repository with at least 16 stars. |
| Public Sponsor | Publicly sponsor an eligible open-source contributor through GitHub Sponsors. This involves payment. |

GitHub controls eligibility and award timing. Check the [profile achievements](https://github.com/WhiteHatHero?tab=achievements) for actual awards. Historical Arctic Code Vault and Mars 2020 achievements are not available through new contributions.

Reference: [Community-maintained achievement catalog](https://github.com/christianalberto/github-profile-achievements).
