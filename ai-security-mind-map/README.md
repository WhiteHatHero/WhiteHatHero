# AI Security Mind Map

By Jordan L. Warren.

[Explore the interactive map](https://jordanwarren.org/ai-security/) · [Open full-screen](https://jordanwarren.org/ai-security/viewer.html) · [Editable tldraw source](AI_Security_Mind_Map.tldr)

A visual study synthesis connecting the five-layer AI stack, prompt injection, jailbreaking, MCP trust boundaries, least privilege, sandboxing, and OWASP risk categories.

## Use

- View the interactive version on my portfolio; drag to pan, zoom, select a card, or switch to Read text.
- Download the `.tldr` file and open it in tldraw to edit the board.
- `viewer.html` is a self-contained viewer implementation that reads the adjacent `.tldr` file. Serve this folder over HTTP to run it locally.

## Sources and scope

Based on my personal Netskope certification study notes and supplemented with public documentation. This is an independent study synthesis, not an official Netskope publication or endorsement. The five-layer stack is a teaching model; risks can span layers. CLI snippets are examples and require version-specific validation.

- [Claude Code security](https://code.claude.com/docs/en/security)
- [Gemini CLI policy engine](https://geminicli.com/docs/reference/policy-engine/)
- [MCP authorization](https://modelcontextprotocol.io/specification/latest/basic/authorization)
- [OWASP GenAI Security Project](https://genai.owasp.org/)
- [OWASP Web Top 10:2025](https://top10.owasp.org/2025/)

Published November 2026. LLM references use the 2025 edition; agentic categories use the 2026 edition.
