## 🚀 Featured Projects

### 🔥 Netforge
**Kubernetes-Powered Network Lab Automation**

Netforge transforms Kubernetes clusters into isolated, fully functional network labs using real containers and virtual machines—not simulations.

Engineers can deploy custom network topologies, troubleshoot routing, DNS, TLS, firewalls, and Netskope integrations, and interact with live environments through a browser.

Built-in packet capture, fault injection, snapshots, and automated reporting simplify complex network troubleshooting.

With native **MCP server and Claude Code integration**, Netforge enables AI agents to deploy, investigate, and document network environments autonomously.

**Technologies:** Kubernetes · Containers · Virtual Machines · Networking · MCP · AI Automation

### 🤖 SecurityMCP / Starfire
**AI-Integrated Cybersecurity Tooling**

An experimental project exploring how locally hosted language models can interact with security tools through controlled execution environments.

Integrates Kali Linux tooling with local AI models to support security testing, reconnaissance, and workflow automation.

**Technologies:** Python · Ollama · Kali Linux · MCP · REST APIs
